você é um profissional de uma empresa de pesquisas sobre astrofísica filial da NASA, e precisa recrutar voluntários para testes de viagens interdimensionais por buracos de minhoca. Usando seus conhecimentos em informática, crie um formulário de cadastro de voluntários de duas etapas (duas páginas de respostas), pedindo: informações pessoais (nome, idade, numero de telefone, cpf, endereço, etc...); informações médicas para garantia de saúde ( tipo sanguíneo, alguma alergia(deverá ter a opção de "nenhum") , histórico de problemas cardíacos (deverá ter a opção de "nenhum"), na segunda pagina, crie um termo de autorresponsabilidade garantindo que a empresa não se responsabiliza em casos de acidentes extremos. o formulário deve ser todo estruturado em html, css e Java script, com todos os campos de coleta de dados sendo gerenciados pelo Java script, para que o usuário seja proibido e enviar qualquer informação em um campo diferente do que ela se refere (como enviar um texto na área de cpf por exemplo. teclas como shift, capslock, entre outras do mesmo tipo, não se enquadram na proibição), caso o usuário tente mesmo assim, a pagina deve exibir um alerta dizendo que aquele campo só aceita um formato de resposta. a pagina deve conter cores simples(como branco, azul, vermelho e verde) e botões mais retangulares (com cantos levemente arredondados). ao encerrar todo o preenchimento do formulário, uma 3° página de agradecimento deverá ser exibida, e um arquivo em pdf (NÃO é permitido o uso de .json ) contendo o formulário respondido será baixado na maquina do usuário. Com o site possuindo 3 paginas, é essencial que cada pagina seja feita separadamente, resultando assim em 3 códigos separados (deverá ter um código para a pagina 1, um código para a página 2 e um terceiro código para a pagina 3)
